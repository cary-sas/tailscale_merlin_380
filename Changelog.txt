Koolshare Asuswrt-Merlin Tailscale Changelog for Merlin 380 armv5 platform
===========================================

v1.0.0
   - add Tailscale插件上线，基于wiregurad协议的零配置内网穿透安全组网工具！
v1.0.1
   - 缩小体积，采用 combined 编译了二进制文件
      CGO_ENABLED=0 GOOS=linux GOARCH=arm GOARM=5 \
      go build -o tailscale.combined \
      -tags "ts_include_cli,ts_omit_aws,ts_omit_bird,ts_omit_tap,ts_omit_kube" \
      -ldflags="-s -w" \
      ./cmd/tailscaled   
   - 修复了一些小的逻辑错误   
v1.0.2
   - 增加了私有化部署选项
v1.0.3
   - Added minimal IPv6 support；
v1.0.4
   - 优化了可执行程序的内存回收的参数；   
v1.0.5
   - 修复了“客户端”角色无法连接到其他节点的问题；  
   - 测试后发现加上内存回收的参数会影响传输速度，在没有找到合适办法前先撤回这个改动； 
v1.0.6
   - 更新登录策略，若 state 文件存在，优先用 state（不带 --authkey）    
v1.0.7
   - 开机启动脚本结合 web UI 开关状态增加了条件判断；  
   - 增加了进程守护逻辑；       
v1.0.8
   - 更新了二进制版本；
   - 重构 Web UI 状态/控制区域，新增 tailscaled 运行状态、tailnet 状态、网口流量状态和刷新按钮；
   - IPv4 改为固定启用，前端 IPv4 选项固定勾选并移除 tailscale_ipv4_enable 配置；
   - 新增“内存优化”开关，仅勾选时才对 tailscaled 使用 GOGC=20 和 GOMEMLIMIT=64MiB；
   - 优化 tailscaled 守护逻辑，增加健康检查、WAN IP 变化自动重启和防火墙规则周期性补回；
   - 调整防火墙/NAT 规则：role=1 且 SNAT 关闭时不再挂载 POSTROUTING -> TSNAT，避免状态检查误报；
   - tailscale up 失败时自动清理半启动状态，并保留脚本真实退出码；
   - 更新 tailscale_status 检查逻辑以匹配固定 IPv4、IPv6 跳过检查和角色规则；
